## 深圳节点卖的是什么：显卡云和裸金属，没有“深圳高防云服务器”

先把结论说清楚：雨云的区域列表里，深圳没有出现在云服务器的可选区域中。第三方整理的区域对照表列了香港 4 区、香港 3 区、美国 1 区、美国 2 区、江苏宿迁、湖北十堰、浙江宁波，没有深圳行，自然也没有深圳的防御数值。所以“雨云深圳高防 150G”“深圳高防 200G”这类说法，目前找不到依据。

深圳实际在售的是两条线。

**显卡云。** 机房在深圳，NVIDIA Tesla V100，16 核 / 24GB 内存 / 16G 显存，50M 上行、200M 下行。日常网吧型 28 元/月起，每月赠 5 小时，超出按 2.5 元/小时计；算力长租型 638 元/月起。这个产品面向的是云电脑、渲染、跑模型这类 GPU 场景，跟网站防御没关系。

**裸金属物理机。** 深圳有两个标准机型：E5-2650v4 标准型，64G 内存、480GB 固态、200M 带宽配 1TB 流量，月付 540 元；E5-2680v4 专业型，64G 内存、960GB 固态、300M 带宽配 2TB 流量，月付 740 元。深圳节点的防御要靠加购 IP 实现，第三方资料记录的口径是：深圳电信 20G+ 防御 IP 约 30 元/月，腾讯 BGP 5G+ 防御 IP 约 50 元/月。这类加购价随区域和线路调整，下单页显示的才是准的。

这三档防御摆在一起，差距很直观：深圳 5G 到 20G+，宿迁 150G 独享，洛杉矶 2 区 200G 可选。如果你的站正在被几百 G 的流量清洗，深圳的方案接不住；如果只是偶尔被小流量扫一下，或者要的是华南低延迟加一层基础防护，深圳物理机加防御 IP 是唯一沾边的选择。

另外要注意，深圳属于国内节点，绑域名对外提供网站服务同样要先备案。

## 高防的钱不在套餐里，这几点最容易被漏算

宿迁的 150G 防御绑在独立 IP 上，这个 IP 单独计价：150 元/月，比很多服务器本身还贵。买宿迁高防机型时，如果只看到“机器 112 元/月”就下单，账单出来大概率超出预期。

其他几档的防御 IP 加购价，第三方记录的口径是：宁波 100G 电信高防 IP 约 30 元/个/月，十堰约 50 元/个/月，深圳电信 20G+ 约 30 元/月、腾讯 BGP 5G+ 约 50 元/月。海外普通独立 IP 5 元/个/月，香港移动高防 IP 40 元/月。这些是加购项，不包含在套餐标价里。

算一笔国内高防的实际年成本：宿迁 2 核 4G 高防机型第三方记录为 112 元/月，年付 7 折后约 78 元/月，加上 150 元/月的独享高防 IP，首年摊下来每月仍在 200 元以上。防御越强，IP 成本占比越高，这是高防产品的普遍结构，不是雨云独有的定价习惯。下单前把“服务器 + 防御 IP + 备案时间成本”三项一起算，再看年付折扣值不值。

## 下单前把这几条对一遍

**NAT 机型不能直接建站。** 雨云不少入门机型默认 NAT 模式，共用公网 IP，只能开 10 到 15 个端口映射。学习 Linux、做内网穿透够用，对外提供网站服务不行，得换独立 IP。

**流量超了是限速，不是停服。** 限流量机型用超后限速到 5M，部分机型 1M，恢复高速要买流量包，大约 100 到 200 元/1TB。香港 2 区同价的两个版本，一个是 50M 带宽配 100GB 月流量，一个是 10M 上传不限流量，选错方向每个月都要多掏钱。

**硬盘默认 30GB。** 扩容按 0.3 到 0.4 元/GB/月（固态）或 0.1 元/GB/月（机械）另计，跑数据库和存镜像的要把这笔算进去。

**一台机器最多 3 个独立 IP。**

**国内节点必须备案。** 宿迁、镇江、宁波、十堰、重庆、深圳，绑域名对外提供网站服务都要先备案；香港、日本、韩国、德国、美国免备案。

**系统支持。** Linux 和 Windows 都能装，宝塔、1Panel 可一键部署。香港 2 区、香港 4 区和湖北十堰支持 macOS，其他区域不支持。
